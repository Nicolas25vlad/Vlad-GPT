# JARVIS Assistant para Fedora

Um assistente pessoal estilo JARVIS integrado ao Linux Fedora, desenvolvido em Python.

## Funcionalidades

- Monitoramento do sistema em tempo real
- Execução segura de comandos
- Interface por voz e texto
- Integração com APIs de IA generativa
- Comandos de linguagem natural
